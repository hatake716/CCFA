# Google Play ストア掲載素材と掲載テキスト案

このディレクトリは Play Console の「メインのストア掲載情報」に使う素材を保持する。

## グラフィック素材

| ファイル | 用途 | 要件 |
|---|---|---|
| `icon-512.png` | アプリのアイコン | 512×512 PNG（32bit）・要件充足済み |
| `feature-graphic-1024x500.png` | フィーチャー グラフィック | 1024×500 PNG・要件充足済み |
| `../docs/images/01〜06-*.png` | スマートフォン スクリーンショット | 1080×2400 / 1080×2122・そのまま利用可 |

再生成する場合は `generator.html` をブラウザで開く（描画完了後にダウンロード
リンクが出る）。マスコットはランチャーアイコンのベクター
（`app/src/main/res/drawable/ic_launcher_foreground.xml`）と同一で、配色・
フォントは `docs/index.html` のデザイントークンに合わせている。

## 掲載テキスト案

- **アプリ名**（最大30文字）: `CCFA（日本語入力対応Linuxコンテナ）`
- **簡単な説明**（最大80文字）:
  `外部アプリ・root不要。日本語IMEがそのまま使えるLinuxコンテナとターミナルをスマホに。`
- **詳細な説明**（最大4000文字）の草案:

```
CCFAは、AndroidスマートフォンだけでLinux環境を動かすためのターミナルアプリです。外部アプリのインストールもroot権限も不要。アプリ内にLinuxコンテナとターミナルを内蔵し、Androidの日本語IMEでかな漢字変換した文字列をそのままLinux CLIへ送れます。

【主な機能】
・Linuxコンテナ: アプリ内で「初期Linux環境を作成」を実行すると、Linux Baseイメージを取得してコンテナを構築します（ユーザー操作起点・要ネットワーク）
・日本語入力対応ターミナル: 日本語IMEの変換結果をそのままCLIに入力可能
・複数コンテナの作成・切替・削除
・ストレージ共有: Androidのフォルダ選択画面で選んだフォルダだけを /workspace/phone/ とミラー同期（スコープドストレージ準拠）
・法的情報画面: 同梱OSSのライセンスと対応ソースをアプリ内で確認可能

【必要環境】
・arm64-v8a（64bit ARM）端末
・コンテナ作成とパッケージ取得時のネットワーク接続

【プライバシー】
CCFA自体が解析・広告・テレメトリー・アカウント等でデータを収集することはありません。詳細: https://hatake716.github.io/CCFA/privacy.html

【オープンソース】
CCFAはApache License 2.0で公開されている独立プロジェクトです。ソースコード: https://github.com/hatake716/CCFA
CCFAは、Anthropic、Canonical、Termux、Apache Software Foundation、Samba Teamその他の第三者の公式製品ではなく、承認・提携・後援を受けた製品でもありません。
```

## データ セーフティ フォームの回答メモ

`PRIVACY.md` / `docs/privacy.html` の内容に基づく:

- データ収集: **なし**（収集・第三者提供とも「いいえ」で申告）
- 暗号化・削除リクエスト設問: 収集なしのため該当なし
- ネットワーク通信はユーザー操作起点の Linux イメージ取得と
  ユーザーが指示したパッケージ取得のみ（アプリの機能としての通信であり
  「ユーザーデータの収集・送信」には該当しない）

## 審査ノート（App access / 審査への補足）に書く内容の要点

- 初回起動後「初期Linux環境を作成」を押すと Ubuntu Base イメージを
  Canonical の配布サーバーからダウンロードする（Wi-Fi 推奨・数百MB）。
- コード実行はアプリ内Linuxコンテナ（PRoot・ユーザー空間）内に限定され、
  端末やネットワークの不正使用ポリシーのインタプリタ/VM除外規定に収まる。
- AI CLI等のサードパーティソフトは同梱・自動インストールしない。
